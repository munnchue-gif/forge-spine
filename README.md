# Forge Spine

**Single source of truth for the living Fabric.**

Local-first · Zero-trust · GPU-first · Capsule-native · Unrestricted coding surface

This is the clean restart. Everything that is not powerful and matching is left behind.

## Core Organs (current)

| Organ | Status | Role |
|-------|--------|------|
| **Gate** | v2 | Forward-declared pathway registry + three-axis auth |
| **Forge** | v1 | Privileged creator: pathways, organs, vessels, policies |
| **Capsule** | v1 | Hot-swap tool loader — .tar/.zip capsules, no permanent install |
| **Ledger** | pending | Hash-chained forensic chronicle |
| **Isolation / Hopper** | pending | Capability membrane + 6-phase ejection |
| **Kernel** | pending | Boot + wiring |

## Design Pillars

1. **One door** — every privileged action is a Capability that passes Gate.
2. **Undeclared = absent** — pathways that are not registered do not exist.
3. **Capsule, never install** — tools arrive as sealed archives, expand into memory/VRAM when needed, collapse when done.
4. **GPU owns the heavy work** — CPU and zram are offload only.
5. **NPU is a separate leg** — light model spliced into the Gate as an always-on observer.
6. **The Substance** — the Fabric is not middleware. It is the medium. Everything that touches it is coated, baptized, and bound.
